# 1000 сложных нод: фактический замер

Замер 17 октября 2026 года: MacBook Pro с Apple M5, 10 CPU-ядер, 24 GB RAM; macOS 26.2; Headless Chrome 155 с ANGLE Metal / Apple M5. Production-сборка Vite, без CPU/network throttling, DPR 1. Загрузка приложения и предыдущий демонтаж сцены не входят в таймер.

Сцена: 1000 карточек, каждая с вложенными Row/Col, текстом, 6 портами, графическим превью и двумя кнопками. Всего **25 001 layout primitive / Konva Group и 26 000 фигур — 51 001 объект Konva**. Виртуализации нет.

| Операция | До дерева layout | Полный Layer.draw | До следующего кадра после draw |
| --- | ---: | ---: | ---: |
| Первый монтаж сцены | 236,5 мс | 98,9 мс | **588,8 мс** |
| Повторный монтаж, медиана 5 прогонов | 189,5 мс | 75,6 мс | **490,9 мс** |
| Повторный монтаж, min–max | 179–210,3 мс | 69,5–80,2 мс | **454,1–508 мс** |
| Повторный layout + принудительный redraw, медиана 3 прогонов | 130,1 мс | 55,1 мс | **253,9 мс** |
| Resize: ширина сцены 6126 → 5626, карточки 230 → 210 | 271 мс | 60,2 мс | **518 мс** |
| Resize обратно | 269,8 мс | 56,2 мс | **482,6 мс** |

Медианы в разных столбцах рассчитаны отдельно. Все 11 прогонов завершились с 1000 карточками, ожидаемым числом групп и фигур, **0 измерительных HTML-узлов и 0 измерительных корней в документе**. Ошибок и предупреждений в консоли не было.

Для первичного монтажа результат — около половины секунды на этой машине. Полная перерисовка всех объектов занимает больше бюджета 16,7 мс для 60 FPS; непрерывный resize всего графа потребует оптимизации. Этот замер не оценивает скорость отдельного перемещения или pan/zoom.

## Что именно измерено

- «До дерева layout» включает React/HTML-монтаж или обновление, ожидание RAF, браузерный CSS layout, чтение bounds/computed styles, сборку дерева и JSON signature. Чистое время CSS layout отдельно не измерялось.
- `Layer.draw()` обёрнут целиком: `drawScene()` и `drawHit()`. Подсчёт объектов исключён из таймера.
- Последний таймер заканчивается на следующем `requestAnimationFrame` после готового canvas. Это граница кадра, а не измерение физического показа пикселей монитором.
- Canvas — 1400 × 760; логическая сцена — 6126 × 11946. Все 1000 нод созданы и обходятся Konva, включая находящиеся за viewport; пиксели ограничены размером canvas. Полная растеризация гигантского bitmap здесь не выполнялась.
- Неизменная геометрия обычно не требует нового canvas draw. В операции `remeasure` бенчмарк специально выполняет полный redraw; результат помечен `forcedRedraw: true`.
- HTML полностью отсоединяется от документа, но portal и его DOM-объекты остаются в памяти. Нулевое число узлов в документе не означает освобождение всей этой памяти.

## Повторить

```sh
npm install
npm run build
npm run preview
```

Откройте `http://localhost:4173/?stress=1`. Кнопки запускают монтаж, повторное измерение и resize. Из DevTools можно вызвать:

```js
await window.layoutStress.run();       // новый монтаж, без предыдущего демонтажа в таймере
await window.layoutStress.remeasure(); // неизменный layout + принудительный redraw
await window.layoutStress.resize();    // изменяет ширину всех 1000 карточек
window.layoutStress.stats();
window.layoutStress.overview(true);    // обзор всех нод, вне измеряемой операции
```
