# Типографика CellText

`CellText` измеряет HTML-текст и передаёт в render-функцию готовые параметры Konva `Text`. Передавайте объект целиком: координаты, размеры и типографика будут взяты из одного измерения.

```tsx
<CellText
  text="Размер, вес и курсив"
  fontFamily="Arial"
  fontSize={22}
  fontWeight={600}
  fontStyle="italic"
  lineHeight={1.25}
  letterSpacing={0.5}
  textDecoration="underline"
  color="#26331e"
>
  {(textProps) => <Text {...textProps} />}
</CellText>
```

| Свойство CellText                   | Значение в callback для Text                                                                                  |
| ----------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| `fontSize`, `fontFamily`            | Разрешённый размер в px и семейство шрифта.                                                                   |
| `fontStyle`, `fontWeight`           | Один Konva `fontStyle`, например `italic 600`. Отдельного native `fontWeight` у Text нет.                     |
| `fontVariant`                       | `normal` или `small-caps`.                                                                                    |
| `lineHeight`, `letterSpacing`       | Множитель межстрочного интервала и межбуквенный интервал в px.                                                |
| `color`                             | Разрешённый CSS-цвет в `fill`.                                                                                |
| `align`, `verticalAlign`            | Горизонтальное и вертикальное выравнивание. CSS `start/end` разрешаются в `left/right` с учётом направления.  |
| `textDecoration`, `underlineOffset` | `underline`, `line-through`, их сочетание и смещение подчёркивания.                                           |
| `wrap`, `ellipsis`, `direction`     | Перенос, многоточие и направление текста.                                                                     |
| `padding`                           | Входит в `x/y` и вычитается из `width/height`; native `padding` равен `0`, чтобы отступ не применялся дважды. |

Набор и смысл native параметров описаны в [Konva.Text API](https://konvajs.org/api/Konva.Text.html). `fill` и `stroke` самого `CellText` сохраняют прежнее значение оформления ячейки; для цвета текста используйте `color`. Дополнительные свойства фигуры, например тень, задавайте на своём `<Text>`.

## CSS и обновление

Свойства `style` имеют приоритет над параметрами компонента. Внутри шрифта порядок такой: параметры компонента → `style.font` → явные `style.fontSize`, `style.fontWeight` и другие longhand-свойства. Shorthand разбирается браузером и передаётся HTML через отдельные свойства, чтобы последующее удаление `font` не сбросило неизменённые значения React. Валидные `font: var(...)` и системные шрифты разрешаются в DOM-контексте.

Canvas может терять наклон при `oblique` с углом. Поэтому `oblique` нормализуется в `italic` и в измерении, и в параметрах Text. Вес шрифта сохраняется числом в строке `fontStyle`; CSS `bolder/lighter` сначала разрешаются браузером.

CSS `textTransform` и схлопывание пробелов адаптируют отображаемый `text` в callback. Исходный `text` компонента не изменяется. Приложение, редактирующее текст, должно хранить исходное значение у себя.

Размер, вес, курсив и остальные параметры участвуют в сигнатурах измерения и кешей. При стабильной числовой/px-ширине изменение типографики текстовой `layoutRoot` измеряет только её. Если ширина относительная, intrinsic, ранее сжата родителем или внешние отступы зависят от размера шрифта, движок пересчитывает родительскую область. Изменившаяся высота в потоке также требует обновления зависимых позиций. Внешние изменения CSS сохраняют консервативную инвалидизацию; после изменения измерительного DOM сторонним кодом используйте `remeasure`. Подробнее: [обновление содержимого](content-updates.md).

## Границы соответствия

- У Konva 8.4.3 нет native `direction` и `underlineOffset`. Значения доступны в callback, но эта версия не реализует соответствующее рисование. Остальные общие параметры проверены на React 16.14.0 / Konva 8 и React 19 / Konva 10.
- У DOM и Konva собственные алгоритмы переноса, shaping, ellipsis и базовой линии. Сложные Unicode-переносы, табуляция и сочетания шрифтов могут давать разные результаты. Полное пиксельное равенство произвольного CSS не гарантируется.
- `wordSpacing`, `fontStretch`, сложные OpenType/variable-font настройки, `writingMode`, отдельные цвет/стиль/толщина декораций и custom `charRenderFunc` не имеют общего соответствия в native Text обеих версий. Не задавайте отличающиеся метрики только в render-функции: HTML не сможет их измерить.
- Для synthetic small caps и наклона CSS `font-synthesis` измерительного host и настоящего canvas должен совпадать. Хостовый canvas остаётся под управлением приложения; библиотека не меняет его стили. В примере `?text=1` одинаковый синтез включён для обеих сторон.

## Проверка

В `?text=1` находятся шесть пар HTML / Canvas: вес и курсив, oblique, интервалы, small caps, декорации, RTL, padding, вертикальное выравнивание и ellipsis. Обе production-сборки прошли по 31 функциональной проверке: смена параметров, CSS shorthand и переменных, сброс шрифта, актуальность кешей, относительные ширины и отступы, локальное измерение и сцена из 1000 элементов. Эти проверки подтверждают адаптацию параметров; ограничения native-рисования выше сохраняются.
