# Карта исходников

Библиотека находится в `src/lib`; демонстрационные приложения используют её публичный API. Вход для потребителя — [`src/lib/index.ts`](../src/lib/index.ts), без импорта демо, Stage или управления камерой.

## Библиотека

| Файл или каталог                                                 | Ответственность                                                                        |

| `measurement/MeasurementPass.ts`, `MeasurementReader.ts`         | Временное подключение HTML и чтение геометрии браузера.                                |
| `measurement/SceneStore.ts`, `MeasurementCache.ts`               | Сохранённое дерево, стабильные ветви и шаблоны геометрии.                              |

| `rendering/Renderer.tsx`, `FullScene.tsx`                        | Выбор видимых нод, плотности кешей и метрик отрисовки.                                 |
| `rendering/SceneIsland.tsx`, `DrawNode.tsx`, `customContent.tsx` | Группы нод, примитивы, функции от границ и замена содержимого ячеек.                   |
| `rendering/PlacedRoot.tsx`, `placements.ts`                      | Независимые позиции, порядок и native drag корней без изменения модели измерения.      |

| `host/`                                                          | Координаты и наблюдение внешних трансформаций Stage, Layer и родительских Group.       |

## Приложения и замеры

- `main.tsx` выбирает пример и загружает его отдельно. `examples/EmbeddedExample.tsx` показывает интеграцию; `DemoCanvas.tsx`, `camera.ts` и `useDemoGestures.ts` принадлежат приложению и создают Stage/Layer и управление камерой.
- `examples/ReferenceNode.tsx` — оформленная нода из `Flex/Cell/CellText`. `DesignedStressScene.tsx` размещает 1000 таких нод с одной декодированной фотографией.
- `examples/FreeNodesExample.tsx` и `freeNodesModel.ts` — свободный граф из 1000 нод: внешний state позиций и порядка, выделение, drag и камера. `?nodes=1` использует один общий `Layout` с `placements`.
- `examples/text-editor/` — собственный редактор демо: textarea, ввод, сохранение, отмена и CSS-позиционирование. Библиотечные компоненты только измеряют текст и не назначают поведение редактирования.
- `App.tsx` собирает playground. В `playground/` находятся сцены, настройки, HTML-инспектор, дерево и копирование результата.
- `StressApp.tsx` собирает стресс-интерфейс. `stress/useStressBenchmark.ts` управляет сценой и операциями `window.layoutStress`; `types.ts` описывает их контракт, `StressResults.tsx` выводит результаты.
- `stress/completedDraw.ts` проверяет готовность геометрии, изображения и качества кеша перед завершением замера. `benchmarks/camera.ts` отдельно считает RAF и завершённые `Layer.draw`; прогрев и загрузка фотографии исключены из соответствующих таймеров.

## Инварианты при изменениях

- После измерения HTML отсоединён от документа; debug подключает измерительный DOM только на время использования. Дополнительным DOM интерфейса приложения владеет само приложение.
- Изменение `text`, стилей, структуры и ограничений размера планирует измерение автоматически. Обновление содержимого независимой `layoutRoot` пересчитывает её ветвь, сохраняя модель, группы и кеши соседей. Если безопасное локальное измерение невозможно, используется полное.
- `invalidate(id)` планирует пересчёт с доступными шаблонами; `remeasure(id)` сбрасывает кеши измерения перед пересчётом. Запросы объединяются через RAF. Подробнее: [обновление содержимого](content-updates.md).
- Внешняя камера остаётся у приложения. Pan/zoom обновляет видимость без HTML layout; библиотека сохраняет pixel ratio существующего Layer.
- Позиции и порядок `placements` относятся к canvas. Измеряемые `children` сохраняют свой порядок; перенос и поднятие ноды не пересчитывают геометрию и не перестраивают её растровый кеш.
- Автоматическая плотность кеша учитывает Layer и трансформации. При нехватке бюджета нода рисуется напрямую.
- `Cell`/`CellText.renderWhen` и `fallback` меняют только canvas-содержимое; HTML и сохранённая геометрия остаются полными. Первый проход измеряет обычную раскладку даже при начальном zoom 0,05. В библиотеке нет порогов LOD и автоматической замены целой ноды. Подробнее: [выборочный LOD](cell-lod.md).
- Публичные компоненты, ref/context и методы `window.layoutStress` сохраняют существующий контракт.

## Проверка рефакторинга до версии 0.5.0

Следующие результаты зафиксированы до перехода на выборочный LOD и описывают прежний вариант сцены.

TypeScript, production-сборки приложения и библиотеки, Prettier и независимый обзор пройдены. Новые тесты и зависимости не добавлялись; поведение проверено в браузере.

В стресс-сцене подтверждены 1000 нод, 35 001 элемент модели, 1035 чтений геометрии, 999 попаданий в шаблон и HTML 0 в покое. При DPR 2 три прогона pan и три zoom дали 60 FPS; это контроль сохранения поведения на текущей машине, без заявления об ускорении относительно предыдущих замеров.

Локальная правка прочитала 35 элементов, сохранив ссылки модели, Konva-группу и растровый кеш соседней ноды. Плотность кеша составила 2 при zoom 1 и 4 при zoom 1,6. В development StrictMode проверены IME, сохранение через blur, отмена Escape и сохранность черновика при внешних rotation/skew.
